# WorldAI Evidence Grid 中文项目说明

Created by Yucong Duan (段玉聪).

WorldAI Evidence Grid 是用于组织实验、来源记录和复现结果的研究原型。它把不同项目中的输入、模型输出、协议和证据放入可追溯的记录中，帮助读者区分本地观察、外部主张和待验证结论。

## 项目内容

- 实验胶囊：记录任务、输入来源、语言、权限和复现参数。
- 多模型适配器：提供模拟、重放及可选外部模型接口。
- 证据记录：分别呈现运行状态、语义稳定性和证据可靠性。
- 复现挑战：把支持、反驳或未决结论附着于具体主张。
- 项目关系目录：保存项目之间的来源和关系信息。

核心实现采用 Python、SQLite 和原生 JavaScript。运行、测试及部署说明见仓库中的源文件与 docs 目录。请为本地部署配置独立的访问凭据。

## 阅读边界

项目中的目录快照和验证记录对应各自的记录时间。它们不能代替独立的现实场景验证，也不代表相关机构的认证或认可。引用其他项目时，应同时查看其原始来源和许可证。
